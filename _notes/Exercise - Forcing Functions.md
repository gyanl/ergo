### Prompt:

**“Redesign the World’s Most Dangerous Interface.”**

Pick any risky scenario (elevator, scooter dashboard, medical form, electric heater, pressure cooker). There must be some risk of injury or death.

Students must redesign it with:

1. **One interlock**
    
2. **One lock-in**
    
3. **One lock-out**

  

**Rules:**

- Each must directly map to a real error a user might make.
    
- They must articulate which error category they’re addressing.
    
- They must justify why a forcing function (not a warning) is needed.

**Output Format**

- Presentation with slides for choice of scenario, and 1-2 slides each for each of the proposed forcing functions added. Use visuals + text to explain how it would work and which error it would reduce and how.
